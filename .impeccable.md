# Life Progress — Design Context

## Users
A single person — the user — using this PWA as a private, contemplative tool to
visualize their entire life as a grid of weeks. They open it in quiet moments
to add a milestone, reflect on a turning point, or simply orient themselves
in time. The audience is global; the app is bilingual-friendly (EN / 中文).

## Brand Personality
**Three words:** Contemplative · Warm · Considered.

The interface should feel like a hand-bound journal, not a SaaS dashboard.
It should give time the gravity it deserves without being morbid; reflective
without being precious; intimate without being twee.

## Aesthetic Direction
**"Literary Memoir."** Inspired by letterpress journals, museum exhibition
captions, Penguin Classics covers, and The New York Review of Books.

- **Typography:** A variable serif (Fraunces) for display & narrative weight,
  paired with a refined neutral sans (Geist) for body and UI. Serif handles
  emotional moments — percentages, titles, milestones. Sans handles affordances.
  Tabular numerals for all life stats.
- **Color:** Warm paper (light) and deep walnut (dark) — never pure white or
  pure black. A single rich accent: **terracotta / burnt sienna**. The
  decade palette progresses like a day, not a rainbow: dawn → morning →
  noon → afternoon → evening → twilight → dusk → night.
- **Layout:** Editorial. Asymmetric. Generous gutters. Hairline rules and
  whitespace as separators — not nested cards. Left-aligned text where
  it earns it. Centered moments only when ceremonial.
- **Decoration:** A single dingbat (❦) and considered typographic rules.
  No glassmorphism. No gradient text on numbers. No drop-shadow chrome.
- **Motion:** Slow, eased entrances. Stagger reveals on first paint.
  Hover scale is restrained. Reduced-motion is honored.
- **Light is the default,** not dark. Life is to be celebrated. Dark mode
  is twilight, not neon.

## Anti-references
- Generic shadcn-on-Tailwind dashboards
- Cyan-on-dark crypto / dev-tool vibe
- Card-inside-card-inside-card nesting
- Gradient-text percentage numbers (the AI-slop fingerprint)
- Centered-everything mobile-first layouts that never adapt

## Design Principles
1. **The grid is the hero.** Every other element serves the visualization.
2. **Words have weight.** Treat copy as editorial, not as labels.
3. **Numbers are sacred.** Use tabular serif numerals, never gradients.
4. **Asymmetry over symmetry.** Editorial layouts feel designed; centered ones feel generated.
5. **Subtraction beats addition.** Remove a card before adding a flourish.
